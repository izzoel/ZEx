# ZEx — ZTV Extractor

A Python-based tool for inspecting video players and HLS manifests.

**Choose your language / Pilih bahasa:**

- 🇮🇩 [Bahasa Indonesia](README.id.md)
- 🇬🇧 [English](README.en.md)

## Quick Start

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
python extractor.py "https://cinema.zetware.id/watch/tmdb-mov-24428"
```

See the documentation for installation details, usage, troubleshooting, and technical notes.
